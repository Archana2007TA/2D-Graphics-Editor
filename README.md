# 2D-Graphics-Editor
Mini-project-2D Graphics Editor in C

Project Description

This project is a menu-driven 2D Graphics Editor developed in C using a 2D character array as a canvas.

The editor allows users to draw and manage basic geometric shapes using ASCII characters.

Features:

Draw Rectangle
Draw Line
Draw Triangle
Draw Circle
Display Picture
Clear Canvas
Change Drawing Character
Input Validation
Menu Driven Interface

Data Structure Used

A 2D character array is used to store the picture.

char pixels[50][100];

Functions Implemented

initializeCanvas()
displayCanvas()
drawRectangle()
drawLine()
drawTriangle()
drawCircle()
isValidPoint()

How to Compile
gcc graphics_editor.c -o graphics_editor

How to Run
./graphics_editor
